# Sound Effects for Shadows & Sparks

Add the following sound effect files to this directory:

1. `card-flip.mp3` - Light card flip sound (0.5s)
2. `damage.mp3` - Sharp zap or impact sound (0.3s)
3. `item-use.mp3` - Soft "ding" or magic sparkle sound (0.5s)
4. `victory.mp3` - Cheerful win jingle (1-2s)
5. `defeat.mp3` - Sad trombone or heartbreak sound (1s)

Recommended specifications:
- Format: MP3
- Bit rate: 128-192 kbps
- Sample rate: 44.1 kHz
- Channels: Mono or Stereo
- File size: Keep under 100KB each

You can find suitable royalty-free sound effects from:
- https://freesound.org/
- https://opengameart.org/
- https://mixkit.co/free-sound-effects/

Make sure to choose sounds that fit the game's dark/mysterious theme while keeping file sizes small for quick loading.
